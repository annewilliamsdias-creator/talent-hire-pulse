AI Video Interview summary text The AI video interview's own written summary (a 2-4 sentence recruiter-facing paragraph, generated by the Portal alongside the score) was only ever readable by opening the full recording/transcript viewer — the score-only view (candidate modal, Interview Guide's AI-Assisted Signals, exported PDF) never showed it, unlike Resume Fitment Vs JD, which has always shown its recommendations text right next to the score. Added the summary text in all three of those places, matching the Resume Fitment treatment exactly. Verified
Confirmed with mock data: summary text renders on Page 6's AI-Assisted Signals block and in the exported PDF's captured HTML.
Exported PDF — page layout (now 4 pages) Evaluation Scores now starts on its own page (page 2), same forced-break treatment Interview Summary and Recruiter Notes already had. Combined with the AI Signals section added last version, the report is now: Page 1 — header, candidate details, Talent+ Gateway AI signals (Resume Fitment + AI Video Interview, each with their score and notes/summary text). Page 2 — Evaluation Scores + Final Recruiter Interview Score. Page 3 — Interview Summary. Page 4 — Recruiter Notes. Verified
Confirmed via the exported HTML's page-break markers with mock data carrying all four sections — exactly 4 pages in the intended order.
"Interview Fitment Score" renamed Renamed to "Final Recruiter Interview Score" everywhere it's shown — the exported PDF, the compact ⭐ chip on the Update Record form, and the "Previous Rounds" history view (both of the latter now show it as a tooltip rather than repeating the full label, since they're small/dense UI). This is the deterministic score computed from this evaluation's own manual 1-5 scores table — the old name collided with the unrelated "Resume Fitment Vs JD" score sitting right next to it in the same report, which is exactly the confusion this renames away. Nothing about how the score is calculated changed, only the label. Verified
Confirmed the old label string no longer appears anywhere in the exported PDF's HTML, and the new label renders with the correct score value.
